# Мануал получения API ключа от Gemini

## 1. Создайте Google аккаунт

Если у вас уже есть Gmail — этот шаг можно пропустить.

Рекомендуется:

* использовать обычный личный Google аккаунт
* включить VPN во время регистрации (на зарубежную страну)
* использовать поддерживаемый регион.



## 2. Откройте Google AI Studio

Перейдите на сайт:

[Google AI Studio](https://aistudio.google.com)

Войдите в свой Google аккаунт и примите условия использования.



## 3. Создайте API Key

Откройте страницу API ключей:

[Gemini API Keys](https://aistudio.google.com/app/apikey)

Нажмите:

```text 
Create API Key
```

или:

```text
Create API key in new project
```



## 4. Скопируйте ваш API Key

После создания появится ключ вида:

```text
AIzaSy...
```

Скопируйте его и сохраните.

Никому не передавайте ваш API ключ.



## 5. Добавьте ключ в бота

В боте откройте:

```text 
Настройки -> Добавить API ключ
```

Отправьте ваш API key и сохраните.

После этого бот автоматически проверит ключ.



# Важно

## Никогда:

* не публикуйте ключ
* не отправляйте ключ другим людям

## Возможные ошибки

### “Invalid API key”

Обычно означает:

* ключ скопирован не полностью;
* случайно добавлены пробелы;
* ключ был удалён.


### “Region not supported”

Gemini доступен не во всех странах.

Попробуйте:

* поменять VPN;
* использовать другой Google аккаунт;
* сменить регион аккаунта.


### “Rate limit exceeded”

Вы превысили бесплатные лимиты API.

Обычно достаточно:

* подождать несколько минут;
* повторить запрос позже.


# Как удалить API ключ

В любой момент вы можете удалить ключ в боте или напрямую:
```text
Настройки -> Удалить API ключ
```
[Google AI Studio API Keys](https://aistudio.google.com/app/apikey)

После удаления бот больше не сможет использовать этот ключ.
